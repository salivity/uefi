EFI 1.x to UEFI 2.x: Key Milestones

The transition from Extensible Firmware Interface (EFI) 1.x to Unified EFI (UEFI) 2.x represents the evolution of modern PC firmware from an Intel-driven initiative into a unified industry standard. This article explores the defining milestones of that shift, including the formation of the UEFI Forum, the release of the UEFI 2.0 and 2.1 specifications, and the technical advancements in cryptography, 64-bit architecture, and networking that permanently replaced legacy PC BIOS.

The Formation of the UEFI Forum (2005)

Prior to 2005, the specification was solely maintained by Intel as EFI, reaching version 1.10 in late 2002. Recognizing that broader industry adoption required vendor neutrality, Intel contributed the EFI 1.10 specification to a newly formed trade group: the Unified EFI Forum. Founded by major technology leaders including AMD, American Megatrends (AMI), Apple, Dell, HP, IBM, Intel, Microsoft, and Phoenix Technologies, this coalition assumed collective ownership of the standard and rebranded it as UEFI.

The Release of the UEFI 2.0 Specification (2006)

In early 2006, the UEFI Forum released the UEFI 2.0 specification, marking the formal shift to the 2.x generation. This milestone accomplished several critical tasks:

  • Vendor-Agnostic Refactoring: Removed Intel-proprietary language, structures, and legacy dependencies present in EFI 1.10 to ensure multi-vendor interoperability across diverse processor architectures.
  • Expanded Processor Architecture Support: Standardized execution environments for AMD64 (x86-64) and Itanium, streamlining the path for full 64-bit platform initialization.
  • Streamlined Code Base: Cleaned up obsolete data tables and deprecated archaic calling conventions left over from the original EFI architecture.

The Release of UEFI 2.1 and Feature Expansion (2007)

While UEFI 2.0 established the new governance and architectural baseline, UEFI 2.1—released in 2007—introduced crucial functional enhancements that distinguished modern firmware from older EFI implementations:

  • Human Interface Infrastructure (HII): Introduced a standardized framework for configuration management, localized strings, and user input, establishing a consistent look and feel across setup utilities.
  • Network Modernization: Added support for IPv6 networking protocols and improved pre-boot networking stacks for Preboot Execution Environment (PXE) booting.
  • Cryptographic Foundation and Authenticated Variables: Introduced authenticated variables and preliminary cryptographic services, which later served as the foundation for modern platform security features such as Secure Boot.

The Formal Deprecation of EFI 1.10

Following the broad adoption of the UEFI 2.x specifications, the UEFI Forum formally superseded EFI 1.10. Operating system vendors, led by Microsoft with 64-bit versions of Windows Vista (Service Pack 1) and Windows Server 2008, committed firmware compatibility exclusively to the UEFI 2.x specification. This alignment by operating system developers, independent BIOS vendors (IBVs), and original equipment manufacturers (OEMs) cemented the 2.x lineage as the definitive standard for pre-boot environments worldwide.
